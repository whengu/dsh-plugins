# requirement — dsh-auto-continue v0.2（最终收敛版）

状态：**需求已与用户逐条对齐**（本文件是规格，代码服从本文件；不写代码行号）
日期：2026-11-17
取代：此前所有版本（v0.1.0 隐式设计、934 行 R2 稿均作废）

## 1. 用户原话（需求唯一来源）

> "我要的东西是 dsh 是异常崩溃的，在下次启动后要自动续跑"
> "肯定要有 ui"、"肯定是开关啊 这个功能肯定要有开关啊"
> "启动时扫 session 目录 难道就必须全量解压扫描吗?"
> "我的建议是插件不要写文件，直接读取最近 N 个，这样最简单"
> "对正在运行的会话，肯定不能再搞他"
> "续会话时的提示词…声明这是系统自动注入的，只是一个'好心的提示'，让模型自己判断任务是否应该继续推进"

## 2. 目标

- **G1 崩溃续跑**：Host 异常崩溃后，下次启动自动续跑崩溃时的那个会话。
- **G2 开关（2026-11-17 用户裁定：取消独立开关）** 不设插件自己的开关。**插件加载即生效**；要关闭就用 DSH 现有的插件禁用机制（`plugin_manager.set_plugin` / 从 profile 移除），不另造配置开关。UI 只读展示，不提供切换控件。
- **G3 无状态**：插件**不写任何文件**、不维护账本、不持跨调用状态。每次启动都是一次纯读判定。
- **G4 轻量发现**：不解压整个日志；只读会话日志**尾部**判定最后边界。
- **G5 不碰活会话**：正在运行（live）的会话绝不 resume/followup。
- **G6 提示词是建议不是命令**：续跑消息明确声明"系统自动注入、仅供参考、由模型自行判断是否继续"。

## 3. 机制（已与用户逐条确认）

**发现（启动时一次）**：
1. `sessionPersistence.list()` 拿会话列表（快照含 `location.path`，~34ms / 646 个）
2. 每个路径 `stat` 取 mtime → 排序 → 取最近 N（默认 10）
3. 对每个候选：`ctx.agents.get(id)` 存在 → 跳过（还在跑）
4. 读该会话 artifact **尾部 64KB**，倒序找最后一个 `turn/start` 或 `turn/end` 边界
   - 实测：21MB 文件 4.9ms、300KB 文件 ~2ms，代价与总大小无关
5. 最后边界是 `turn/start` → 判定为崩溃遗留 → 续跑

**续跑（DSH 全权，插件只调两个入口）**：
- `ctx.agents.resume({resumeSessionId: id})` —— 恢复会话（DSH 内部补 closers、拿写所有权；插件不碰）
- `handle.agent.followup(建议消息)` —— 排一条 user 消息唤醒一轮
- 插件持有 handle，卸载时 `dispose()`（官方形态，`dsh-agent/README.zh.md:32`）
- 恢复后再 `ctx.agents.get(id)` 校验仍归属自己，避免重复

**开关**：无独立开关，插件加载即生效。关闭=D SH 现有插件禁用机制（用户裁定，避免重复造开关）。

## 4. 验收判据

| # | 判据 | 怎么判 |
|---|---|---|
| A1 | 尾部判定正确：开放→续、关闭→跳、无边界→跳 | 用真实/合成 artifact 断言 |
| A2 | 只读尾部不读全文：判定路径不出现全量 `getStoredLog` 式读取 | 静态 + 运行时断言读取字节上界（≤64KB/会话） |
| A3 | 启动时只处理最近 N 个：N 之外不被读尾部 | stub 断言尾部读次数 ≤ N |
| A4 | live 会话不被碰 | `agents.get` 返回非空的 id 不触发 resume/followup |
| A5 | 插件不写任何文件 | 源码无 `writeFile`/`appendFile`；运行时断言零写 |
| A6 | 续跑走 DSH 入口 | 断言调用 `agents.resume` + `agent.followup`，插件不改日志 |
| A7 | 提示词声明"自动注入、仅供参考、由模型判断" | 断言消息正文含该语义子串 |
| A8 | 插件未加载时零动作（无独立开关，禁用插件即关闭） | 不加载插件跑一次：无会话扫描（由"插件未加载"这一事实保证） |
| A9 | handle 生命周期：持有并在卸载时 dispose | stub 断言 dispose 被调用 |

## 5. 技术约束

- **T1** 插件不 import 任何 `@deepseek-ai/*`（profile 的 node_modules 实测解析不到这些包），宿主服务全部经 `ctx` 取。
- **T2** 客户端 lazy-CJS（`window.__ModuleLoader__.load`），自带控件，只用 `--dsw-alias-*` token，不 require Harness Client 包。
- **T3** 多帧 zstd 尾部读需精确定位帧边界（用帧头 frame content size，不能靠裸 magic 扫描）。
- **T4** 只从 tarball 安装（安装需用户单独授权）。
- **T5** 单进程独占（用户裁定：不会同时跑多个 Host），无需加锁。

## 6. 提示词要求（用户明确）

续跑消息必须包含：
1. 这是**系统自动注入**的提示，不是用户的真实指令；
2. 它只是一个**"好心的提示"**，仅供参考；
3. **由模型自己判断**任务是否应该继续推进、是否已完成、是否需要先核实外部状态；
4. 若判断任务已完成或不应继续，**直接结束，不要重复执行**；
5. 保留 DSH closers 的"结果不可知、有副作用先核实、不要盲目重试"语义。
